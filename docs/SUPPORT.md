# Support Guide

For user-facing support, see the root [SUPPORT.md](../SUPPORT.md).

## Maintainer checklist

When triaging issues:

- Ask for sanitized logs.
- Confirm whether the result is Deepbrid Official or external/prechecked.
- Confirm deployment method and `BASE_URL` shape.
- Check whether Stremio is using stale cached streams.
- Never request API keys or private tokens.
