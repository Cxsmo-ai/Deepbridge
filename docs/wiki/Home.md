# Deepbridge Wiki

Deepbridge is a self-hosted Stremio addon for people using Deepbrid with extra sources. It combines official Deepbrid streams, your Deepbrid torrent library, built-in Easynews, built-in Newshosting, Nexus/Miatrix website search, optional external Newznab/Prowlarr indexers, and the optional Deepbrid Usenet Finder browser bridge.

Start here if you are new:

1. Read [What Deepbridge Does](What-Deepbridge-Does).
2. Follow [Full Setup Checklist](Full-Setup-Checklist).
3. Install it with [Docker Quick Start](Docker-Quick-Start) or [Oracle Cloud Podman Guide](Oracle-Cloud-Podman-Guide).
4. Open the dashboard and follow [Dashboard Configuration](Dashboard-Configuration).
5. Add the generated manifest URL to Stremio.
6. If you use Nexus/Miatrix on Oracle, read [Nexus Miatrix Source](Nexus-Miatrix-Source) and [Oracle Nexus Only WireGuard](Oracle-Nexus-Only-WireGuard).
