# Support

Thanks for using Deepbridge.

## Before opening an issue

Please check:

1. [Troubleshooting](docs/TROUBLESHOOTING.md)
2. [FAQ](docs/FAQ.md)
3. Existing GitHub issues

## What to include

Include:

- Deepbridge version or commit SHA.
- Deployment type: local Node.js, Docker, Compose, reverse proxy, hosted VM.
- Sanitized logs.
- Stremio platform: desktop, Android TV, web, etc.
- Whether the result is Deepbrid Official or external/prechecked.

Do not include:

- Deepbrid API keys.
- Indexer API keys.
- Stremio configuration tokens.
- Private IP addresses or SSH details.
- Full final playback URLs.

## Security issues

Please do not open public issues for security-sensitive problems. See [SECURITY.md](SECURITY.md).

## Dashboard support panel

The web dashboard includes a project-support section with a Deepbrid referral guide. This is part of the intended user-facing dashboard experience and is documented in [docs/DASHBOARD.md](docs/DASHBOARD.md).

If you are self-hosting a fork, you may customize that support panel in `public/index.html`, but please keep support/referral behavior clear in your own documentation.
